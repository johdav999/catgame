# Browser toolchain notices

These unmodified license texts accompany the pinned Emscripten 6.0.11 browser
runtime and its `emdawnwebgpu` port. `Emscripten.txt` comes from Emscripten's
root LICENSE; `Dawn.txt` comes from the installed port's
`emdawnwebgpu_pkg/webgpu_cpp/LICENSE` (Dawn & Tint Authors, 2017–2025).
The port's `webgpu/src/LICENSE` is the same Emscripten license text.
Recheck the notices when changing the SDK/port. Other library notices are
copied from the pinned WebEngine and Jolt sources during browser staging.
