# Loading presentation

The initial HTML shell and retained game loading view share an evergreen
gradient, cream Paws wordmark, original paw seal and a single cream status card.
Both retain Fraunces and Nunito Sans. The HTML shell uses a slow orbit around
the seal; the retained view uses three activity dots driven by its existing
frame timestamp. Reduced motion disables these effects. Neither invents a
percentage or changes scene preparation, save ownership or readiness gates.

Loading has no Back button or scrollable menu footer. The retained status is
announced once as a live region. Error recovery retains Retry and its existing
failure controls. Account/cloud launch controls are hidden during loading.

Browser checks on the generated port-8080 site covered 1600x1000, 390x844 and
844x390: one loading status, no Back-to-garden button, and successful transition
to the garden. Screenshots are in `build/evidence/loading-polish/`.
