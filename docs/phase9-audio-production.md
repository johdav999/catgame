# Prompt 9 audio production checklist

No audio is generated by this script. All 47 deliveries require real source files and review.

Use ElevenLabs Sound Effects for the 44 effects/ambience clips and Suno Custom / Instrumental with empty lyrics for music. Retain the best original download without renaming away its format. Do not substitute another music provider.

Per clip: retain source ID/link, exact prompt/settings/date and account use-rights evidence in `artifacts/audio-production/sources/`. Edit a copy, audition, trim/clean and export PCM16 WAV. Short dry effects should be mono; music/air can be stereo. Keep peak <= -2 dBFS, no clipping, and at most 24 MiB decoded at the browser device sample rate (usually 48 kHz). Budget retained PCM at 48 MiB; the backend may duplicate active buffers. Prefer mono music if a 90-second stereo track exceeds the budget.

Loops must be pre-trimmed to the full WAV buffer: the pinned backend loops the entire buffer, with no subrange or sample-accurate crossfade. Audition five repeats in-game and retain sample boundaries, waveform and seam review. Do not set accepted/listening fields before those checks. Music transitions use a short fade-out, release, then fade-in without overlapping decoded tracks.

Place edited WAVs under `artifacts/audio-production/edited/`, record metadata using [the import template](../artifacts/audio-production/import-template.json), and run `python scripts/import-audio.py <metadata.json>`. Originals stay outside the deployed tree. Runtime destinations follow. Missing files remain absent, with no silent placeholders.
